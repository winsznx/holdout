# Compiler eval inputs

Rules: written by the builder (Tim) in his own words, split into single rules. Not independent volunteers.
Labels: drafted by Claude and committed before the compiler was run on these rules. Every rule is labeled refuse because none sets a number or sizing threshold that one of the eight templates can test (risk per trade as a percent, a count of losses per day, moving a stop, size after a win or a loss, going all in). max_leverage needs a number, daily_loss_limit takes USDT not a count, no_add_to_loser is about adding to a losing position, not sizing after a win.
